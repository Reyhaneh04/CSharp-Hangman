# C# Hangman Game

A Hangman word-guessing game developed using C# and Windows Forms.

The game allows users to select a word category, play the game, save their results, and view previous game results. An admin section provides word management, game time settings, and access to game results.

## Features

### User

- Select a word category
- Play the Hangman game
- Guess the selected word by entering letters
- Save game results
- View previous game results

### Admin

- Add new words
- Edit existing words
- Set the game time limit
- View game results

## Technologies

- C#
- Windows Forms
- .NET
- Visual Studio

## Game Overview

Hangman is a word-guessing game in which the player tries to discover a hidden word by guessing letters.

For each incorrect guess, another part of the Hangman figure is displayed. The player must guess the word before the allowed attempts or time runs out.
